# 설계 문서

입력단 확장 관련 설계. 두 기능 모두 **기존 파이프라인 뒷단을 건드리지 않고
입력단 어댑터만 추가**하며, 서로 독립적이다. 둘 다 GPU를 쓰지 않으므로
별도 백그라운드에서 처리해 오토라벨링·학습을 막지 않는다.

| 문서 | 요약 | 상태 |
|---|---|---|
| [video-ingest.md](video-ingest.md) | 동영상 업로드 → 프레임 추출 → `raw/` → 오토라벨링 재사용 | 설계 |
| [dataset-upload.md](dataset-upload.md) | 외부 YOLO 데이터셋 zip 업로드 → 검증/정규화 → 학습 소스로 등록 | 설계 |

## 전체 그림 (두 기능 반영 후)

```
[입력 A] 이미지/zip ─┐
[입력 B] 동영상 ──── 프레임추출 ─┴─→ raw/ → 오토라벨링 → 리뷰 → export ─┐
                                                                        │
[입력 C] 외부 데이터셋 zip ──── 검증/정규화 ──→ datasets/ ──────────────┤
                                                                        ▼
                                                          학습 (소스 무관) → .pt
                                                                        │
                                                          모델 레지스트리 등록 ─┐
                                                                        ▲       │
                                                                        └───────┘ (선순환)
```
