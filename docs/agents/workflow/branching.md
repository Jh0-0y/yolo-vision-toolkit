# 브랜치

> 개발은 `develop` 에서 하고 `main` 에는 PR 로만 들어간다. 작업을 시작할 때 읽는다.

| 브랜치 | 용도 |
|---|---|
| `main` | 배포 가능한 상태. **PR 로만 병합한다** |
| `develop` | 개발 브랜치. 일상 작업은 전부 여기서 한다 |

- **`feature/*` 브랜치를 만들지 않는다.** 작업은 `develop` 에 직접 커밋한다.
- **`main` 에 직접 커밋하지 않는다.**
- **지시받지 않은 브랜치 생성·전환·삭제를 하지 않는다.** 지금 있는 브랜치에서 작업한다. 다른 브랜치가 필요해 보이면 먼저 묻는다.
- 커밋 메시지는 [커밋 메시지](commit-messages.md) 를 따른다.
- 병합 절차와 올리기 전 검증은 [PR](pr.md) 을 따른다.
