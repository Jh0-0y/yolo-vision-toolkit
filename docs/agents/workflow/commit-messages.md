# 커밋 메시지

> 접두사와 형식. 커밋 메시지를 쓸 때 읽는다.

## 형식

```
<prefix>: <subject>
```

한 줄. 접두사는 영어, **제목은 한국어**로 쓴다. 마침표는 붙이지 않아도 된다.

제목은 **개조식**으로 끝낸다 — "~추가", "~수정", "~로 이관". 문장으로 늘어놓지 않는다.

## 허용 접두사 — 이 여섯 개뿐이다

| 접두사 | 쓰는 경우 |
|---|---|
| `feat` | 새 기능 |
| `fix` | 기존 동작의 버그·문제 수정 |
| `refactor` | 동작 변화 없는 구조 변경 (이름 변경, 추출, 재배치) |
| `build` | 빌드 도구·의존성 변경 (Docker, CI 설정, 패키지 버전) |
| `docs` | 문서 또는 주석만 바꾼 변경 |
| `test` | 테스트 추가·수정 |

**새 접두사를 만들지 않는다.** 목록에 없는 것이 필요해 보이면 위 여섯 중 가장 가까운 것을 고른다.

## 예시

```
feat: 영상 프레임 추출에 타일링 옵션 추가
fix: 잡 매니저의 BrokenProcessPool 복구 처리 수정
refactor: 크롭 좌표 계산을 adaptive-crop 어댑터로 분리
build: adaptive-crop 을 0.0.1-rc1-20260811 태그로 고정
docs: 계층 경계 규칙을 docs/agents 에 정리
test: 크롭 어댑터 계약 테스트 추가
```

## 본문

선택이다. **빈 줄로 제목과 분리**하고, 한국어로 쓴다.
디프만 봐서는 알 수 없는 **왜**를 적는다 — 무엇을 했는지는 디프가 말한다.
줄은 **72자 안팎**에서 감는다.
